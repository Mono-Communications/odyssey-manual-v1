# 10. DB 설정

<mark style="color:red;">**`application.yml`**</mark>의 <mark style="color:green;">`spring.datasource.hikari`</mark> 영역에서 데이터베이스 연결 정보와 운영 옵션을 설정합니다.

```yaml
spring:
  datasource:
    hikari:
      driver-class-name: com.mysql.cj.jdbc.Driver
      jdbc-url: jdbc:mysql://{{ip}}:{{port}}/{{database}}?useUnicode=true&characterEncoding=UTF-8&useSSL=false&allowPublicKeyRetrieval=true
      username: {{id}}
      password: {{pw}}
      limit: 24
      backup: FIXED
      charset: UTF-8|UTF-8
```

### <mark style="color:blue;">**limit**</mark> - 메시지 발송 타임아웃

현재 시각 기준 **`limit`** 시간 이전에 예약된 메시지는 발송하지 않고 타임아웃 실패 처리합니다.

* 예) **`limit=12`**, 현재 시각 14시 → 02시 이후 예약 메시지만 발송, 02시 이전 메시지는 실패 처리

### <mark style="color:blue;">**backup**</mark> - 로그 테이블 분할 정책

로그 테이블(**`rv-submit-log`**)이 누적되면 조회·백업이 어려워집니다. 발송량에 따라 분할 정책을 선택합니다.

<table><thead><tr><th width="178.5999755859375">값</th><th width="210.39990234375">의미</th><th>테이블명 예시</th></tr></thead><tbody><tr><td><strong><code>FIXED</code></strong></td><td>로그테이블 고정 사용</td><td><mark style="color:red;"><code>ODYSSEY_LOG</code></mark></td></tr><tr><td><strong><code>YEAR</code></strong></td><td>연도별 분할</td><td><mark style="color:red;"><code>ODYSSEY_LOG_2026</code></mark></td></tr><tr><td><strong><code>MONTHLY</code></strong></td><td>월별 분할</td><td><mark style="color:red;"><code>ODYSSEY_LOG_202604</code></mark></td></tr><tr><td><strong><code>DAILY</code></strong></td><td>일별 분할</td><td><mark style="color:red;"><code>ODYSSEY_LOG_20260427</code></mark></td></tr></tbody></table>

### <mark style="color:blue;">**charset**</mark> - DB 인코딩

DB 통신 시 인코딩과 디코딩에 사용할 charset을 <mark style="color:red;">`|`</mark>로 구분하여 입력합니다.

* 예) <mark style="color:red;">`UTF-8|UTF-8`</mark> → encoding / decoding 모두 UTF-8 사용



## <mark style="color:blue;">권장 설정 (발송 환경별)</mark>

{% hint style="warning" %}
**자주 하는 실수**

1. **`limit`을 너무 짧게 설정** — 대량 예약 발송 환경에서 `limit=`<mark style="color:red;">`1~2`</mark>로 설정하면 02시 이전 예약 메시지가 전부 실패 처리됩니다. 대량 예약 환경은 반드시 <mark style="color:red;">`24`</mark> 이상으로 확보하세요.
2. **`backup=`**<mark style="color:red;">**`DAILY`**</mark>**&#x20;+ 보관 정책 부재** — 일별 로그 테이블이 무한 누적됩니다. 별도 보관 주기(예: 90일 이후 삭제) 정책을 함께 마련하세요.
3. **패스워드 평문 입력** — 운영 환경에서는 반드시 OTP 기반 암호화 적용 후 암호문을 입력하세요. ([9..md](9..md "mention") 참조)
{% endhint %}

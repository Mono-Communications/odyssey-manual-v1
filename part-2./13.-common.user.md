# 13. 기본 설정 (common.user)

```yml
common:
  user:
    shutdownhooker: 25201
    file-size: 512000
    file-upload: 109
    ping-time: 20
    ping-delay: 50
    restart-delay: 5
    multiply-count: 4  
    rcsfile-yn: false
    rcs-auto-upload: false
    auth-dir: ./auth
    file-dir: ./upload
    filelist-check-interval: 86400
    retry-report-interval: 60000
    otp: MONO
    puase: 
      start-time: 0
      end-time: 0
      start-day-time: 0
      end-day-time: 0
      puase-time-spam-action: 0
      day-time: 0
    kisa-orig-code: ''
    agencykey: {{agency_key}}
    brandid: {{brand_id}}
    brandkey: {{brand_key}}
    rcs-phone-cache-yn: false
    rcs-phone-cache-del: 1
    cdrid: 0
    etc: ''
    ha-node-num: 0
    rcs-stat-info: true
```

## <mark style="color:blue;">발송 금지 시간 (pause)</mark>

발송 금지 시간은 <mark style="color:red;">**`application.yml`**</mark>에 직접 설정하지 않습니다.

Web UI의 "발송 금지 시간" 화면에서만 편집 가능하며, 설정 값은 <mark style="color:red;">`PAUSE_INFO`</mark> 테이블에 저장됩니다.

{% hint style="danger" %}
**반드시 설정하세요.** 광고성 메시지는 **정보통신망법에 따라 야간(21:00 \~ 익일 08:00) 발송이 금지**되어 있습니다. 해당 시간대를 차단하지 않으면 과태료 대상이 될 수 있으므로, 광고성 메시지를 발송하는 환경이라면 반드시 야간 차단을 설정해야 합니다.
{% endhint %}

# 8-1. senderId.yml

{% hint style="info" %}
해당 파일 설정은 GSMS 발송 고객사에 한해 유효하며, **GSMS 발송 서비스를 사용하지 않는 고객사와는 무관**합니다.
{% endhint %}

#### 예시

* 예시값은 가상의 값이며, key/value 매핑은 고객사에 맞게 설정해주세요.
* 모든 key와 value 값은 따옴표("")로 감싸는 것을 권장합니다.

```yml
sender-id:
  "1": "10001000"
  "82": "12345678"
  "86": "SENDERID"
  "default": "MonoComm"
```

* key 값은 해당하는 국가 코드입니다.
  * \[예시] 한국 — 82 : "12345678" 로 변환 및 발송
* value 값은 해당 국가 코드에 따라 치환되는 <mark style="color:red;">**`sender-id`**</mark> 입니다.
* <mark style="color:green;">**`"default"`**</mark> — 국가코드가 없거나 잘못 입력된 경우 기본적으로 대체되는 sender-id 값입니다. <mark style="background-color:$danger;">**"default" 의 key 는 절대 변경하면 안 되며**</mark>, value 값은 고객사에 맞게 변경해주세요.

{% hint style="info" %}
<mark style="color:$primary;">**\[참고]**</mark> GSMS는 실발송번호가 아닌 <mark style="color:red;">**`sender-id`**</mark>로 발송됩니다.
{% endhint %}

(GSMS 발송과 관련된 추가 내용 ㅇ참고)

# 12. 테이블명 & 건수 & 주기 설정

<mark style="color:green;">`common.tables`</mark> 영역에서 Odyssey가 사용할 테이블명, 서비스 별 초당 발송 건수, 폴링 주기를 설정합니다.

```yaml
common:
  tables:
    table-name:
      rv-submit: ODYSSEY
      rv-submit-log: ODYSSEY_LOG
      rv-stat: ODYSSEY_STAT
      rv-file: ODYSSEY_RCSFILE
      rv-phone: M2X_INVALID_PHONE
      rv-rcs-stat: RCS_STAT
      rv-tmpl-stat: ODYSSEY_TEMPLATE_STAT
    fetch-count:
      sms: 500
      lms: 500
      mms: 40
      vms: 40
      gsms: 500
      rcs: 500
      kakao: 500
      fetch: 1000
    cycle:
      fetch: 1000
      db-check-interval: 30000
```

### <mark style="color:blue;">table-name</mark> - 자동 생성 테이블명

***

기본값을 그대로 사용하며, 고객사 DB에 같은 이름의 기존 테이블이 있는 경우에만 충돌 방지를 위해 변경합니다. 운영 중 변경 시 기존 발송 데이터와의 연결이 끊어지므로 신규 환경 설치 시점에만 조정하세요.



### <mark style="color:blue;">fetch-count</mark> - 서비스별 초당 발송 건수

***

각 서비스가 1초당 DB에서 가져와 발송할 최대 메시지 건수입니다. **각 세션의 `max-cnt` 합과 같거나 약간 크게** 설정하는 것이 원칙입니다.

#### - 권장 기본값

* 세션(계정) 1개 당 기준값입니다. 세션이 n개 있을 경우 권장값 × n 의 값을 설정해주세요.
* 권장 기본값은 발송 규격에 따라 다릅니다. 각각의 메시지 타입이 <mark style="color:green;">**`KT`**</mark> / <mark style="color:green;">**`CPAAS`**</mark> 중 어떤 **`transmisson`** 을 통해 발송되는지 확인 후 설정해주세요.
  * 세션 별 transmission 설정은 [14. 계정 설정 (sessions)](14.-sessions/)을 참고

## <mark style="color:blue;">권장 설정 (발송량별)</mark>

| 발송 환경                 | fetch-count 조정                | cycle.fetch |
| --------------------- | ----------------------------- | ----------- |
| 소량 (월 100만 건 미만)      | 기본값 유지                        | 1000 (기본)   |
| 중량 (일 평균 10만\~100만 건) | 세션 1\~2개 추가 + 합산 max-cnt와 동기화 | 1000 (기본)   |
| 대량 (일 100만 건 이상)      | 세션 다수 추가 + 비례 조정              | 500 \~ 1000 |

{% hint style="info" %}
처리량은 <mark style="color:red;">`fetch-count`</mark> 증가가 아니라 <mark style="color:blue;">**세션 추가 + 합산**</mark> <mark style="color:red;">`max-cnt`</mark> <mark style="color:blue;">**동기화**</mark>로 늘립니다. <mark style="color:red;">`fetch-count`</mark>만 키우면 차이만큼 DB 부하만 증가하고 게이트웨이가 차단합니다.
{% endhint %}

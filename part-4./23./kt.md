# KT 크로샷 재접속 차단 기능

KT 크로샷으로 메시지(SMS/LMS/MMS)를 발송 중 특정 결과 코드를 수신할 경우, 세션을 끊고 재접속을 차단합니다. 이 경우 **원인을 해결한 뒤 Odyssey를 재구동**해야 세션 접속이 다시 가능합니다.

| 결과코드 | 설명                     |
| ---- | ---------------------- |
| 1    | 시스템 장애                 |
| 2    | 인증 실패 (인증 파일을 찾을 수 없음) |
| 5    | 인증 티켓 유효성 오류           |
| 6    | 가입 정보 없음               |
| 7    | 계정 패스워드 틀림             |
| 8    | 계정 일시정지                |
| 9    | 해지된 계정                 |
| 10   | 계정이 존재하지 않음            |
| 11   | 이미 연결되어 있음             |
| 17   | 인증 권한 없음 (접근 가능 IP 아님) |
| 18   | 다른 IP 로 중복 접속함         |
| 29   | 인증 티켓 만료               |

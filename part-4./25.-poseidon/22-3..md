# 22-3. 자주 묻는 질문

{% hint style="info" %}
#### **Q. 연동하면** Odyssey **성능에 영향이 있습니까?**

메트릭 수집은 인메모리 집계이며, 전송은 30초마다 300\~500바이트 **HTTP** 요청 1회입니다. 발송 스레드와 분리된 전용 스레드에서 수행되므로 발송 처리량에 영향을 주지 않습니다.
{% endhint %}

{% hint style="info" %}
#### **Q. Poseidon에서 우리 서버에 접속하거나 설정을 변경할 수 있습니까?**

불가능합니다. 통신은 고객사 → **Poseidon** 단방향이며, **Poseidon**이 **Odyssey**로 명령을 전달하는 경로는 없습니다.
{% endhint %}

{% hint style="info" %}
#### **Q. 발송 내용(전화번호·문구)이 외부로 나갑니까?**

나가지 않습니다. 전송 항목은 집계 수치와 오류 정보뿐입니다 — 전송 데이터 및 통신 규격
{% endhint %}

{% hint style="info" %}
#### **Q. 일시적으로 연동을 끄고 싶습니다.**

<mark style="color:red;">`poseidon.enabled: false`</mark> 로 변경 후 **Odyssey**를 재시작하면 즉시 전송이 중단됩니다. 방화벽 정책은 그대로 두어도 통신이 발생하지 않습니다.
{% endhint %}

{% hint style="info" %}
#### **Q. 오류 수집만 끄고 지표는 계속 보내고 싶습니다.**

<mark style="color:red;">`poseidon.cypher.enabled: false`</mark> 로 설정하십시오. 하트비트와 메트릭은 계속 전송됩니다.
{% endhint %}

{% hint style="info" %}
#### **Q. 인증 키가 유출된 것 같습니다.**

모노커뮤니케이션즈로 재발급을 요청해 주십시오. 재발급 시 기존 키는 폐기되며, <mark style="color:red;">`config/system.yml`</mark> 의 `auth-key` 교체 후 재시작이 필요합니다.
{% endhint %}

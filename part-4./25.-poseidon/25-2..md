# 25-2. 아웃바운드 방화벽 허용

Poseidon 연동을 사용하려면 **고객사 방화벽에서 Odyssey 서버의 아웃바운드(**<mark style="color:red;">**`outbound`**</mark>**) 통신을 허용**해 주셔야 합니다.

### <mark style="color:blue;">**고객사 방화벽 - Poseidon 서버 IP 등록**</mark>

**Poseidon**은 고객사 서버의 상태를 **가져가는(pull) 방식이 아니라, Odyssey가 보내는(push) 방식**으로 수집합니다. **Odyssey**가 30초마다 자기 상태를 외부의 **Poseidon**으로 송신하는 구조이므로, 이 송신 경로가 열려 있지 않으면 **수집·감시 기능**이 전혀 동작하지 않습니다.

이 구조 덕분에 보안 관점에서는 아래가 **보장**됩니다.

<table><thead><tr><th width="181">항목</th><th>내용</th></tr></thead><tbody><tr><td><strong><code>통신 방향</code></strong></td><td>고객사 → <strong>Poseidon 단방향</strong></td></tr><tr><td><strong><code>인바운드 포트 개방</code></strong></td><td><strong>불필요</strong> — <strong>Poseidon</strong>이 고객사로 접속하는 경로가 없습니다</td></tr><tr><td><strong><code>원격 제어</code></strong></td><td>없음 — <strong>Poseidon</strong>은 <strong>Odyssey</strong>에 명령을 내리거나 설정을 변경하지 않습니다</td></tr><tr><td><strong><code>VPN / 전용선</code></strong></td><td>불필요 — <strong>HTTP(S)</strong> 아웃바운드만으로 동작</td></tr><tr><td><strong><code>대상 범위</code></strong></td><td>지정된 단일 호스트·포트 1개소로 한정</td></tr><tr><td><strong><code>고객사 DB 접근</code></strong></td><td>없음 — <strong>Poseidon</strong>은 고객사 DB에 접속하지 않습니다</td></tr></tbody></table>

### <mark style="color:blue;">차단시 잃게 되는 기능</mark>

Odyssey의 발송 기능 자체는 계속 동작하지만, **모니터링 기능이 전부 무력화**됩니다.

<table><thead><tr><th width="181">잃게 되는 것</th><th>구체적 영향</th></tr></thead><tbody><tr><td><strong><code>생존 감시</code></strong></td><td><strong>Odyssey</strong> 프로세스가 중단되어도 <strong>Poseidon</strong>이 알 수 없습니다. 장애 인지가 "고객 문의 발생 시점"까지 지연됩니다.</td></tr><tr><td><strong><code>성능 지표 축적</code></strong></td><td>큐 적체·응답 지연·실패율 상승 같은 <strong>장애 선행 징후를 관측할 수 없어 선제 조치가 불가능</strong>합니다.</td></tr><tr><td><strong><code>오류 수집 · 분석</code></strong></td><td>어떤 예외가 어느 단계에서 몇 번 발생했는지 이력이 남지 않습니다. 사후 원인 분석도 고객사 서버 로그를 직접 확보해야만 가능해집니다.</td></tr><tr><td><strong><code>장애 알림</code></strong></td><td>담당자에게 알림이 발송되지 않습니다.</td></tr><tr><td><strong><code>복구 소요 시간 (MTTR)</code></strong></td><td>지표·이력이 없어 재현과 추정에 의존하게 되므로 원인 규명과 복구가 지연됩니다.</td></tr></tbody></table>

{% hint style="info" %}
#### **차단 상태여도 발송에는 영향이 없습니다**

**Poseidon** 전송은 발송 파이프라인과 분리된 전용 스레드에서 수행되며, 전송 실패는 경고 로그만 남기고 무시됩니다. \
즉 방화벽이 닫혀 있거나 **Poseidon**이 점검 중이어도 **문자 발송은 정상 진행**됩니다. 다만 그 기간의 지표와 오류 이력은 복구되지 않고 유실됩니다.
{% endhint %}

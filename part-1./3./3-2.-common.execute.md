# 3-2. 사용 메시지 종류 (common.execute)

발송할 메시지 종류만 `true`로 설정합니다. 사용하지 않는 종류는 `false`로 두면 불필요한 DB 폴링이 줄어 부하가 낮아집니다.

```yaml
common:
  execute:
    sms: true
    lms: true
    mms: true
    rcs: false       # RCS 사용 시 true
    kakao: false     # 카카오 알림톡/친구톡 사용 시 true
    fetch: true      # 로그 이관 (HA 운영 시 true 권장)
```

# 3-7. RCS 발송 시 추가 설정 (common.user)

CPaaS RCS로 발송하는 경우 다음 KEY를 입력합니다. RCS 청약 시 발급받습니다.

```yaml
common:
  user:
    agencykey: {{agency_key}}    # 대행사 KEY
    brandid: {{brand_id}}        # 브랜드 ID
    brandkey: {{brand_key}}      # 브랜드 KEY
```

yamlCopy

> **참고:** RCS를 사용하지 않는 환경은 빈 문자열(`''`) 또는 키 자체를 생략해도 됩니다.

# 7-4. 광고성 메시지 야간 차단 미설정

**증상**: 21:00 \~ 익일 08:00 시간대에 광고성 메시지 발송 후 **정보통신망법 위반 통지**

**점검**:

* Web UI "발송 금지 시간" 화면에서 야간 차단을 드래그로 설정 ([20. Web UI 상세](../../part-4./20.-web-ui/) 참고)
  * 설정값은 `PAUSE_INFO` 테이블에 저장

{% hint style="danger" %}
광고성 메시지는 **정보통신망법에 따라 야간(21:00 \~ 익일 08:00) 발송이 금지**되어 있습니다.
{% endhint %}

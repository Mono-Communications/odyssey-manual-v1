# 7-6. Web UI 접속 불가

**증상**: 브라우저로 `http://[ip]:[port]` 접속 시 연결 거부

**점검**:

* 기동 모드가 <mark style="color:red;">**`multi`**</mark>인지 확인 (pipeline 모드는 Web UI 미제공)
* 서버 방화벽에서 <mark style="color:red;">**`server.port`**</mark>(기본 `7090`) inbound 허용
* <mark style="color:red;">**`application-HA.yaml`**</mark>의 `server.port` 값과 실제 접속 포트 일치 여부

# 7-2. 세션 인증 실패

**증상**: 기동은 되지만 발송 시 <mark style="color:$danger;">`Auth Fail`</mark> / <mark style="color:$danger;">`Login Fail`</mark> / <mark style="color:$danger;">`req_regist 실패`</mark> 등의로그 반복

**점검**:

* KT 크로샷: <mark style="color:red;">**`auth-file`**</mark> 값과 **`auth/`** 폴더의 <mark style="color:red;">**`.cert`**</mark> 파일명이 **대소문자까지 정확히 일치**하는지 확인
* KT RCS / CPaaS: `rcs-id`/`rcs-secret` 또는 `api-id`/`api-pw` 발급값 확인
* 패스워드 암호화 적용 시 <mark style="color:green;">`common.user.otp`</mark>와 암호문 짝 확인

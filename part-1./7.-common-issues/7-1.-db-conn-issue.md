# 7-1. DB 접속 실패

**증상**: **`logs/live/system.log`**&#xC5D0; <mark style="color:$danger;">`Communications link failure`</mark> 또는 <mark style="color:$danger;">`Access denied for user`</mark> 에러

**점검**:

* <mark style="color:red;">**`application.yml`**</mark>의 <mark style="color:green;">`jdbc-url`</mark>/<mark style="color:green;">`username`</mark>/<mark style="color:green;">`password`</mark> 값 확인
* DB 서버에서 Odyssey 서버 IP의 outbound 접속 허용 여부
* MySQL 8.x인 경우 <mark style="color:red;">`useSSL=false&allowPublicKeyRetrieval=true`</mark> 파라미터 필요
* 패스워드 암호화 사용 시 <mark style="color:green;">`common.user.otp`</mark> 값과 암호문 짝이 맞는지 확인

# 2-3. auth 폴더

<figure><img src="https://mono-communications.github.io/odyssey-manual/images/Odyssey%20%ED%8C%A8%ED%82%A4%EC%A7%95%20-%20auth%20%ED%8F%B4%EB%8D%94%20%EB%82%B4%EB%B6%80.png" alt="그림 6. auth 폴더 내부 (.cert 인증파일)"><figcaption><p>그림 6. auth 폴더 내부 (.cert 인증파일)</p></figcaption></figure>

KT 크로샷 세션 인증파일(`.cert`)을 보관합니다. 세션마다 다른 파일이 들어가며, 파일명은 `application-HA.yaml`의 `kt.sessions[].auth-file` 값과 정확히 일치해야 합니다.

{% hint style="info" %}
<mark style="color:$primary;">**참고 :**</mark> `.cert` 파일은 대소문자를 구분합니다. Linux 환경에서 특히 주의하세요.
{% endhint %}

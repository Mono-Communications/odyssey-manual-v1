# 2-3. auth 폴더

<figure><img src="../../.gitbook/assets/6_auth_내부.png" alt="그림 6. auth 폴더 내부 (.cert 인증파일)"><figcaption><p>그림 6. auth 폴더 내부 (.cert 인증파일)</p></figcaption></figure>

KT 크로샷 세션 인증파일(**`.cert`**)을 보관합니다. 세션마다 다른 파일이 들어가며, 파일명은 <mark style="color:red;">`application.yaml`</mark>의 <mark style="color:red;">`kt.sessions[].auth-file`</mark> 값과 정확히 일치해야 합니다.

```yaml
kt:
    sessions:
    - seq: 1
      rcs-ip: {ip 주소}
      sp-id: test
      sp-pwd: {암호화 된 계정비밀번호}
      end-user: test
      auth-file: test.cert        # auth/ 의 .cert 파일과 파일명 일치
      max-cnt: 200
      sms: true
      lms: true
      mms: true
      vms: true
```

{% hint style="info" %}
**`.cert`** 파일은 대소문자를 구분합니다. Linux 환경에서 특히 주의하세요.
{% endhint %}

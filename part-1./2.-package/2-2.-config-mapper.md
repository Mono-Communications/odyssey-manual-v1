### **동작 원리**

Odyssey는 시작 시 매퍼를 다음 순서로 로드합니다.

1. **외부 우선** — `./config/mapper/{dbms}/*.xml` 에 파일이 1개 이상 있으면 외부 폴더 사용
2. **classpath fallback** — 외부 폴더가 비어있거나 누락되면 jar 안에 동봉된 기본 매퍼 사용 (안전망)

시작 로그에서 어느 경로가 사용 중인지 확인할 수 있습니다.

```
# 외부 폴더 사용 시 (정상)
INFO MyBatis mappers: external [file:./config/mapper/mysql/*.xml] -> 5 files

# 또는 fallback 시
INFO MyBatis mappers: classpath fallback [classpath:/mapper/mysql/*.xml] -> 5 files
```

### **운영 워크플로우**

```bash
# 1. 매퍼 수정
vi config/mapper/mysql/selectQuery.xml

# 2. 재시작 (변경사항 반영)
./stop.sh
./start.sh multi
```

{% hint style="info" %}
<mark style="color:$primary;">**참고 :**</mark> 핫 리로드는 지원하지 않습니다. 변경 후 반드시 재시작하세요.
{% endhint %}

{% hint style="warning" %}
XML 문법 오류가 있으면 기동에 실패합니다. 변경 후 반드시 시작 로그에서 매퍼 로드 결과를 확인하세요.
{% endhint %}

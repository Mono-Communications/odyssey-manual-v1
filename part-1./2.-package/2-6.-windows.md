# 2-6. Windows 전용 파일

Windows 패키지에는 운영자가 직접 사용하는 .bat 파일 4개와, Windows 서비스 등록 시 자동으로 사용되는 wrapper 파일들이 들어있습니다.

<table><thead><tr><th width="200">파일</th><th width="416.5999755859375">역할</th><th>직접 실행/편집</th></tr></thead><tbody><tr><td><code>start.bat</code> / <code>stop.bat</code></td><td>수동 실행 / 정지 (Linux <code>start.sh</code> / <code>stop.sh</code> 와 1:1 대응)</td><td>✅</td></tr><tr><td><code>installService.bat</code> / <code>unInstallService.bat</code></td><td>Windows 서비스 등록 / 해제 (UAC 자동 요청, 메뉴로 multi/pipeline 선택)</td><td>✅</td></tr><tr><td><code>Odyssey.exe</code></td><td>WinSW (Windows Service Wrapper) — 서비스에 등록되는 실행 파일</td><td>❌</td></tr><tr><td><code>Odyssey-multi.xml</code> / <code>Odyssey-pipeline.xml</code></td><td>모드별 서비스 설정 template</td><td>❌</td></tr><tr><td><code>Odyssey.xml</code> (자동 생성)</td><td>active 서비스 설정 — <code>installService.bat</code> 시 동적 생성, <code>unInstallService.bat</code> 시 자동 삭제</td><td>❌</td></tr></tbody></table>

{% hint style="warning" %}
`Odyssey.exe`, `Odyssey*.xml` 은 `installService.bat` 가 자동으로 처리하는 내부 파일입니다. **운영자 혹은 고객지원팀이 직접 실행하거나 편집할 필요가 없습니다.**
{% endhint %}

실제 운영 시나리오와 명령은 [4. 실행 / 정지](../4.-start-stop.md) 참고

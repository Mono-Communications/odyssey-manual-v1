# 2-6. Windows 전용 파일

Windows 패키지에는 운영자가 직접 사용하는 <mark style="color:red;">`.bat`</mark> 파일 4개와, Windows 서비스 등록 시 자동으로 사용되는 wrapper 파일들이 들어있습니다.

<table><thead><tr><th width="241">파일</th><th width="313.5999755859375">역할</th><th>직접 실행/편집</th></tr></thead><tbody><tr><td><strong><code>start.bat</code></strong> / <strong><code>stop.bat</code></strong></td><td>수동 실행 / 정지 (Linux <mark style="color:red;"><code>start.sh</code></mark> / <mark style="color:red;"><code>stop.sh</code></mark> 와 1:1 대응)</td><td>✅</td></tr><tr><td><strong><code>installService.bat</code></strong> / <strong><code>unInstallService.bat</code></strong></td><td>Windows 서비스 등록 / 해제</td><td>✅</td></tr><tr><td><strong><code>jenv.bat</code></strong> / <strong><code>renv.bat</code></strong></td><td>서비스 실행 시 필요한 내부 환경 변수(JAVA_HOME 등) 로드 및 세팅</td><td>❌</td></tr><tr><td><strong><code>nssmX64.exe</code></strong> / <strong><code>nssmX86.exe</code></strong></td><td><mark style="color:red;"><code>installService.bat</code></mark> 실행 시 백그라운드 서비스 등록을 처리하는 외부 모듈 (NSSM)</td><td>❌</td></tr></tbody></table>

{% hint style="warning" %}
직접 실행/편집이 필요하지 않은 파일은 서비스 실행 시 혹은<mark style="color:red;">`installService.bat`</mark> 가 자동으로 처리하는 내부 파일입니다. **운영자 혹은 고객지원팀이 직접 실행하거나 편집할 필요가 없습니다.**
{% endhint %}

실제 운영 시나리오와 명령은 [4. 실행 / 정지](../4.-start-stop.md) 참고

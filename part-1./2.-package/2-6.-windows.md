# 2-6. Windows 전용 파일

Windows 패키지에는 운영자가 직접 사용하는 <mark style="color:red;">`.bat`</mark> 파일 4개와, Windows 서비스 등록 시 자동으로 사용되는 wrapper 파일들이 들어있습니다.

<table><thead><tr><th width="217">파일</th><th width="313.5999755859375">역할</th><th>직접 실행/편집</th></tr></thead><tbody><tr><td><strong><code>start.bat</code></strong> / <strong><code>stop.bat</code></strong></td><td>수동 실행 / 정지 (Linux <mark style="color:red;"><code>start.sh</code></mark> / <mark style="color:red;"><code>stop.sh</code></mark> 와 1:1 대응)</td><td>✅</td></tr><tr><td><strong><code>installService.bat</code></strong> / <strong><code>unInstallService.bat</code></strong></td><td>Windows 서비스 등록 / 해제</td><td>✅</td></tr><tr><td><strong><code>Odyssey.xml</code></strong> (자동 생성)</td><td>active 서비스 설정 — <mark style="color:red;"><code>installService.bat</code></mark> 시 동적 생성, <mark style="color:red;"><code>unInstallService.bat</code></mark> 시 자동 삭제</td><td>❌</td></tr></tbody></table>

{% hint style="warning" %}
<mark style="color:red;">**`Odyssey.xml`**</mark> 은 <mark style="color:red;">`installService.bat`</mark> 가 자동으로 처리하는 내부 파일입니다. **운영자 혹은 고객지원팀이 직접 실행하거나 편집할 필요가 없습니다.**
{% endhint %}

실제 운영 시나리오와 명령은 [4. 실행 / 정지](../4.-start-stop.md) 참고

# 4. 실행 / 정지

배포 패키지에는 사전 빌드된 thin jar(`odyssey-app-1.0.0.jar`, `odyssey-pipeline-1.0.0.jar`)와 번들 JRE(`jre/`), 외부 라이브러리(`lib/`)가 포함되어 있어, 별도 빌드 없이 바로 기동할 수 있습니다.

## Linux <a href="#linux" id="linux"></a>

Odyssey 설치 폴더에서 다음 명령을 실행합니다.

`start.sh` 는 자동으로 적절한 Java 를 선택하고<mark style="color:$info;">(</mark><mark style="color:$info;">`jre/`</mark> <mark style="color:$info;"></mark><mark style="color:$info;">동봉 시 번들 JRE, 미동봉 시 시스템 Java 21)</mark> 외부 `lib/` 를 classpath 와일드카드로 인식합니다.

— 어느 쪽이든 운영자가 별도 설정할 것은 없습니다 (자세히는 [2-5 jre 폴더](https://mono-communications.github.io/odyssey-manual/#2-5-jre-%ED%8F%B4%EB%8D%94-%E2%80%94-%EB%B2%88%EB%93%A4-jre) 참고).

```bash
# 시작 — multi 모드 (엔진 + Web UI)
./start.sh multi

# 시작 — pipeline 모드 (엔진 단독)
./start.sh pipeline

# 정지 (graceful, 최대 30초 대기)
./stop.sh

# 강제 정지
./stop.sh all force
```

{% hint style="info" %}
<mark style="color:$primary;">**참고 :**</mark> 첫 실행 전 한 번만 실행 비트 복원: `chmod +x start.sh stop.sh` (번들 JRE 동봉 시 `chmod -R +x jre/bin` 도 함께 실행)
{% endhint %}

## Windows <a href="#windows" id="windows"></a>

Windows 패키지는 두 가지 운영 모드를 제공합니다.

— **수동 실행** (테스트/임시) 과 **Windows 서비스 등록** (24/7 운영, 권장).

### 수동 실행

cmd 또는 탐색기 더블클릭으로 실행. 사용자 로그인 세션에 묶여 있어 로그아웃 시 종료됩니다.

```cmd
start.bat                    :: 메뉴로 multi/pipeline 선택
start.bat multi              :: 또는 인자로 직접
stop.bat                     :: 모두 정지
```

### Windows 서비스 등록 (24/7 운영)

`installService.bat` 더블클릭(또는 cmd 실행) → UAC 권한 자동 요청 → 메뉴에서 모드 선택 → **서비스 등록 + 시작이 한 번에 처리됩니다.** <mark style="color:$info;">(부팅 시 자동 시작 + 죽으면 자동 재시작 + 사용자 로그아웃 무관 동작.)</mark>

<figure><img src="https://mono-communications.github.io/odyssey-manual/images/Odyssey%20%ED%8C%A8%ED%82%A4%EC%A7%95%20-%20window%20installer.png" alt="그림 24. installService.bat 실행 — 모드 선택 후 서비스 자동 등록 + 시작"><figcaption><p>그림 24. installService.bat 실행 — 모드 선택 후 서비스 자동 등록 + 시작</p></figcaption></figure>

```cmd
installService.bat           :: 메뉴로 multi/pipeline 선택
installService.bat multi     :: 또는 인자로 직접
unInstallService.bat         :: 서비스 정지 + 등록 해제
```

#### 등록 후 운영:

```cmd
sc query Odyssey             :: 상태 확인
net stop Odyssey             :: 정지
net start Odyssey            :: 시작
```

또는 `services.msc` 에서 "Odyssey" 항목 우클릭으로 GUI 조작 가능.

{% hint style="warning" %}
수동 모드와 서비스 모드를 동시에 실행하지 마세요 (포트/DB 락 충돌). 한 모드만 골라 운영. 설치 경로는 한글/공백 없는 영문(예: `C:\Odyssey\`) 권장.
{% endhint %}

## 정상 기동 확인 <a href="#undefined" id="undefined"></a>

`log/agent.log`(또는 모드별 `log/odyssey-app.out` / `log/odyssey-pipeline.out`)에 다음과 유사한 메시지가 출력됩니다.

```
Java: ./jre/bin/java (bundled JRE (./jre))
MyBatis mappers: external [file:./config/mapper/mysql/*.xml] -> 5 files
Database Driver Load Success.
DBMS=[MySQL], URL=jdbc:mysql://**.**.**.**/****
Mono Messaging Service agent=[Odyssey-1.0.0] starts.
Exist Table Name=[ODYSSEY]
Exist Table Name=[ODYSSEY_RCSFILE]
SendKT Thread Start
```

{% hint style="info" %}
<mark style="color:$primary;">**참고 :**</mark> 시작 로그의 핵심 줄 — `Java: ...` (어느 Java 사용 중), `MyBatis mappers: external ...` (외부 매퍼 정상 로드), `Poseidon integration disabled` (Poseidon 미연동 환경에서만, 정상). 자세히는 [2-5 jre 폴더](https://mono-communications.github.io/odyssey-manual/#2-5-jre-%ED%8F%B4%EB%8D%94-%E2%80%94-%EB%B2%88%EB%93%A4-jre), [2-2 매퍼 외부화](https://mono-communications.github.io/odyssey-manual/#2-2-configmapper-%ED%8F%B4%EB%8D%94-%E2%80%94-%EB%A7%A4%ED%8D%BC-%EC%99%B8%EB%B6%80%ED%99%94), [16장 Poseidon](https://mono-communications.github.io/odyssey-manual/#16-poseidon-%EB%AA%A8%EB%8B%88%ED%84%B0%EB%A7%81-%EC%97%B0%EB%8F%99) 참고.
{% endhint %}

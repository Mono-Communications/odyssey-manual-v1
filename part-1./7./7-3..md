# 7-3. 발송은 시작되는데 결과가 안 오는 경우

**증상**: `STATUS=1` (전송 중) 상태로 멈춰 있음.

**점검**:

* 게이트웨이 outbound 방화벽 (KT 크로샷 IP/PORT는 [21장 게이트웨이 IP / PORT](https://mono-communications.github.io/odyssey-manual/#21-%EA%B2%8C%EC%9D%B4%ED%8A%B8%EC%9B%A8%EC%9D%B4-ip--port) 참고)
* `report-cycle` 값이 너무 길지 않은지 (기본 `5000ms`)
* KT RCS의 `webhook-port`를 사용한다면 inbound 방화벽 허용 확인

# 5. Web UI 살펴보기

**`multi`** 모드로 기동한 경우, 브라우저로 다음 주소에 접속하면 Web UI가 표시됩니다.

```
http://[서버IP]:[포트]
```

기본 포트는 <mark style="color:red;">`application-HA.yaml`</mark>의 <mark style="color:red;">`server.port`</mark> 값(`8090`)입니다.

<figure><img src="../.gitbook/assets/9_모니터링_대시보드.png" alt="그림 9. 모니터링 대시보드 — 실시간 발송 현황 (파이프라인, 큐 사이즈, TPS, 리소스 게이지)"><figcaption><p>그림 9. 모니터링 대시보드 — 실시간 발송 현황 (파이프라인, 큐 사이즈, TPS, 리소스 게이지)</p></figcaption></figure>

첫 화면은 **모니터링 대시보드**로, 파이프라인·큐 사이즈·TPS·CPU/메모리 게이지를 실시간으로 보여줍니다.

좌측 사이드바에서 데이터베이스·상세 설정·세션 설정·발송 금지 시간·로그·이중화 등 다른 화면으로 이동할 수 있습니다.

전체 화면 구성과 사용법은 [20. Web UI 상세](../part-4./20.-web-ui/)를 참고하세요.

{% hint style="info" %}
pipeline 모드(엔진 단독)에서는 Web UI가 제공되지 않습니다. 결과는 로그(<mark style="color:$danger;">`log/agent.log`</mark>)와 DB(**`ODYSSEY`** 테이블의 **`RESULT`** 컬럼)로 확인합니다.
{% endhint %}
